# SOC Phrasebook

Useful phrases for SOC work. Review 5 before each session; once a week, cover the English column and say them from the Spanish.

| Phrase | Meaning (ES) |
|---|---|
| The alert was a false positive. | La alerta fue un falso positivo. |
| I escalated the ticket to Tier 2. | Escalé el ticket a Tier 2. |
| We found three IOCs: an IP, a domain and a hash. | Encontramos tres IOCs (indicadores de compromiso): una IP, un dominio y un hash. |
| I isolated the host from the network. | Aislé el equipo de la red. |
| The attacker has had access since Monday. | El atacante tiene acceso desde el lunes. |
